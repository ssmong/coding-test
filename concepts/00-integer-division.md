# 음수 나눗셈 — 파이썬 `//` vs C++ (0 방향 절삭)

## 핵심
- **파이썬 `//` = floor (음의 무한대 방향)**, **C++ = truncation (0 방향 절삭)**.
- **피제수가 음수이고 안 나누어떨어질 때만** 달라진다.

| `a / b` | 파이썬 `a // b` | C++ (문제 기준) |
|---|---|---|
| `-7 / 4` | -2 | **-1** |
| `-1 / 4` | -1 | **0** |
| `7 / 4` | 1 | 1 (양수 동일) |
| `-8 / 4` | -2 | -2 (나누어떨어지면 동일) |

## 해결 (C++식 0 방향 절삭)
```python
int(a / b)        # float 나눈 뒤 int() 절삭. 값이 작으면 간단·안전
-(-a // b)        # 정수만. a<0, b>0 가정 (-a 양수 → // 절삭 → 부호 복구)
-(abs(a) // b)    # "양수로 바꿔 몫 → 음수로" 문제 설명 그대로
```

## 함정
- **`a // b`를 그냥 쓰면 음수에서 틀린다** (가장 흔한 실수). C++ 기준 문제는 변환 필수.
- **`int(a / b)`는 값이 ~9×10¹⁵ 넘으면 float 정밀도가 깨져 틀릴 수 있다** → 큰 값이면 정수 트릭 `-(-a // b)`. (14888은 ±10억 이내라 `int(a/b)`로 충분.)
- 양수끼리거나 나누어떨어지면 `//`와 결과 같음 — 그래서 작은 테스트만 보면 버그를 못 잡을 수 있다. **음수+나머지 케이스를 꼭 확인.**
