# 격자 90° 회전 (전치 + 뒤집기)

## 언제 쓰나

1. **4방향 동작을 1방향으로 압축.** "왼쪽으로 밀기"만 만들고 보드를 회전시켜 재사용 → 코드·버그 표면 1/4 (12100 2048).
2. 문제가 직접 회전을 요구할 때 (조각 회전, 배열 돌리기).

회전을 직접 인덱스로 짜지 말 것. **전치(대각 반사) + 행 뒤집기(수평 반사)** = 회전. 반사 두 번이 회전 한 번이다.

## 코드

```python
def rotate_ccw(board):
    """반시계 90°. 4번 호출하면 원래대로."""
    return [list(row) for row in zip(*board)][::-1]

def rotate_cw(board):
    """시계 90°."""
    return [list(row) for row in zip(*board[::-1])]
```

`[::-1]`이 `zip` **밖**이면 반시계, **안**이면 시계. 헷갈리면 2×2로 손 검산이 제일 빠르다.

### 왜 `zip(*board)`가 전치인가

`*board`는 각 행을 별개 인자로 푼다 → `zip([1,2,3],[4,5,6],[7,8,9])`.
`zip`은 "각 인자의 i번째"를 묶으므로, 묶인 결과가 곧 **i번째 열**.

```
1 2 3     zip(*board)    1 4 7      [::-1]    3 6 9
4 5 6    ───────────>    2 5 8    ────────>   2 5 8
7 8 9      (전치)        3 6 9    (행 뒤집기)  1 4 7
```

오른쪽 끝 열 `3 6 9`이 맨 윗줄로 → 반시계 90°.

### 4방향 순회 관용구

```python
cur = board
for _ in range(4):
    do_something(move_left(cur))   # 매번 다른 방향이 "왼쪽"이 됨
    cur = rotate_ccw(cur)          # 4번째에 원본으로 복귀 → 되돌릴 필요 없음
```

시계/반시계 어느 쪽이든 4방향을 전부 훑는다 — 방문 **순서**만 다르다.

## 함정

- **`zip`은 튜플을 낸다.** `list(row)`로 감싸지 않으면 이후 `board[i][j] = x`가 `TypeError`. 지금 당장 대입을 안 해도, 보드 표현이 튜플로 오염되면 다른 함수에서 물린다. 회전 결과는 항상 `list`로 되돌려라.
- **`zip`은 가장 짧은 인자에 맞춰 조용히 잘라낸다.** 행 길이가 들쭉날쭉하면 에러 없이 데이터가 사라진다. 직사각 보드에서만.
- **비정방(N×M) 격자는 회전 후 차원이 뒤바뀐다** (N×M → M×N). `H`, `W`를 캐싱해 뒀다면 회전 후 반드시 다시 계산.
- **매 회전이 새 보드를 만든다** (O(N²) 복사). N ≤ 20에 회전 수천 번이면 무시 가능하지만, 핫 루프에서 수만 번 돌면 in-place 회전이나 인덱스 매핑을 고려.
