# 정렬 불변식 유지 (매 턴 재정렬 금지)

## 언제 쓰나
칸마다 여러 개체가 쌓이고 "나이가 어린 것부터" 처리해야 하는 시뮬레이션.
매 사이클 `sort()` 하면 O(cycle × N² × k log k)로 터진다.

## 핵심 관찰
- 처음 입력만 한 번 정렬 → 칸별 컨테이너에 순서대로 넣으면 오름차순으로 시작.
- 이후 살아남은 개체는 **모두 나이가 똑같이 +1** → 상대 순서 불변.
- 새로 태어난 개체는 **항상 최연소(나이 1)** → 앞쪽에만 붙이면 됨.
- 결과: `[신규] + [기존 생존자]` 이어붙이기만으로 정렬 상태가 공짜로 유지.

## 코드
~~~python
from collections import deque

cells = [[deque() for _ in range(n)] for _ in range(n)]

data.sort()                       # (age, r, c) — 최초 1회만
for age, r, c in data:
    cells[r][c].append(age)       # 각 칸 오름차순 완성

# 사이클 중: 어린 것부터 = 왼쪽부터 popleft
# 번식 시: appendleft(1)  또는 신규 리스트를 앞에 붙여 재조립
~~~

## 함정
- 같은 칸에 개체 여러 개가 들어올 수 있다. 칸당 스칼라 하나로 두면 바로 틀림.
- 생존자를 뒤에서부터 처리하면 순서가 뒤집힌다. 항상 왼쪽(어린 쪽)부터.
- 죽은 개체를 순회 중 제거하려 하지 말고, 살아남은 것만 새 컨테이너로 옮겨 담는다.
