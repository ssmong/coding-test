# 0-1 BFS (가중치 0/1 최단경로)

## 언제 쓰나
간선 비용이 **0 또는 1**뿐일 때. 예: 13549 숨바꼭질3 (`×2`=0초, `±1`=1초). 다익스트라보다 빠르고(deque, 로그 없음) 코드도 짧다.

## 핵심
- 0-cost 간선 → `appendleft`(큐 앞), 1-cost 간선 → `append`(큐 뒤). 그러면 큐가 거리 오름차순 유지.
- **visited 플래그 + enqueue 시점 확정은 틀린다.** 반드시 **완화(relaxation)**: `dist[x]+w < dist[nx]` 일 때만 갱신.

## 코드
~~~python
from collections import deque
INF = float('inf')

def zero_one_bfs(n, k, limit):
    dist = [INF] * (limit + 1)
    dist[n] = 0
    q = deque([n])
    while q:
        x = q.popleft()
        for nx, w in ((x + 1, 1), (x - 1, 1), (2 * x, 0)):
            if 0 <= nx <= limit and dist[x] + w < dist[nx]:   # 완화
                dist[nx] = dist[x] + w
                q.appendleft(nx) if w == 0 else q.append(nx)
    return dist[k]
~~~

## 함정
- **`if dist[nx] == UNVISITED` 게이트로 쓰면 오답.** 1-cost 간선(+1)이 0-cost 간선(×2)보다 먼저 노드를 찜하면, 더 짧은 0-cost 경로가 영영 막힘. 예: `0→2`는 1인데 2로 나옴 (`x=1`에서 `+1`이 `dist[2]=2` 선점 → `×2`(dist 1) 스킵). → `INF` 초기화 + `<` 비교(완화).
- **범위 체크를 배열 접근보다 먼저.** `if 0 <= nx <= limit and dist[nx]...` (단락 평가). 거꾸로면 `dist[-1]` wrap(조용한 오답) / IndexError.
- 답은 큐 다 비운 뒤 `dist[k]` 읽으면 안전. pop 시점 early-return도 가능하나 deque 단조성 이해 필요.
