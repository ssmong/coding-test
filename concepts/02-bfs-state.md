# 상태 차원 BFS — visited에 상태 축 추가

> [02-bfs-grid.md](02-bfs-grid.md)는 좌표만으로 방문 관리. 이 노트는 **(좌표 + 상태)를 한 노드로** 보는 확장판.

## 언제 쓰나
- "벽을 **딱 한 번** 부술 수 있다" (2206), "벽 **K번**" (14442)
- "말처럼 **K번** 점프 가능" (1600), "**T초** 안에 도착, 그람 줍기" (17836)
- 공통 신호: **같은 칸에 와도 "어떤 자원/상태로 왔는지"에 따라 이후가 달라진다.**

## 핵심 통찰
좌표가 같아도 상태가 다르면 **서로 다른 노드**다.
→ `visited`(또는 `dist`)를 한 차원 늘린다: `dist[x][y][state]`.
한 상태로 이미 방문했어도 **다른 상태로는 더 짧게 올 수 있으니** 막으면 안 된다.

## 골격 (전이 로직은 문제마다 TODO)
```python
# 벽 부순 횟수 0/1 → 상태 2개
dist = [[[-1] * 2 for _ in range(m)] for _ in range(n)]
q = deque([(0, 0, 0)])          # (x, y, broke)
dist[0][0][0] = 1               # 칸 수 세는 문제면 시작=1
while q:
    x, y, b = q.popleft()
    for d in range(4):
        nx, ny = x + dx[d], y + dy[d]
        if not (0 <= nx < n and 0 <= ny < m):

        # TODO: 벽인데 아직 안 부쉈으면(b==0) 상태 1로 진행
```

## 함정
- **상태별로 따로 방문 체크.** `dist[nx][ny][nb] == -1`을 봐야 한다. `dist[nx][ny]`만 보면 다른 상태 경로를 통째로 막아 오답.
- **상태 차원 크기 = 가능한 상태 수.** 벽 1개=2, 벽 K개=K+1. K가 크면 `n*m*(K+1)` 메모리 폭발 주의.
- **도착 칸은 상태 무관.** BFS라 먼저 닿는 쪽이 최단 → `(N-1, M-1)`에 어느 상태로든 처음 도착하면 그게 답. 두 상태 중 작은 값 비교는 보통 불필요(먼저 pop된 게 최소).
- 시작 거리: 칸 수를 세는 문제(2206)는 시작을 **1**로, 이동 횟수면 **0**으로.
