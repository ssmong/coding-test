## 현재 강점 / 약점 요약

업데이트 일자: 2026-06-24

**강점**
- 완화(relaxation) 개념을 0-1 BFS(13549) → 다익스트라(1753)로 전이 — 첫 다익스트라 본체를 한 번에 정확히 (2000 랜덤그래프 전수일치). 알고리즘 핵심 이해도 양호
- 문제 지문의 동사 순서를 그대로 코드 순서로 옮기는 습관 (3190에서 "머리→벽→몸→사과/꼬리" 순 정확 이행)
- board 값을 상수로 추상화 (`EMPTY/APPLE/SNAKE`, `RIPE/UNRIPE/WALL`) → 분기가 바로 읽힘
- BFS 첫 문제(7576)에서 dist=-1 sentinel 통합 + 멀티소스 시작점 일괄 enqueue 정확히 적용
- 7576 재제출에서 행/열 경계·답추출·매직넘버는 self-교정 (단 `main()` 호출 누락은 2206서 재발 → 패턴 등재)
- 상태 차원 BFS(2206) 구조 자체는 한 번에 정확히 세움 — 상태축 분리·상태별 방문체크·조기종료 모두 의도대로

**약점**
- **🔴 리스트 생성 시 괄호 위치 (3연속: 1753, 1916, 4485) — 현재 1순위 약점.** `[X*n]`(길이1)↔`[X]*n`(n개 복제), `str(x for..)`↔`str(x) for..`. 곱셈/생성이 조용히 "되긴 돼서" 에러가 늦게 터짐. **처방: 2D/배열은 항상 `[... for _ in range(n)]`** (곱셈 함정 없음), 한 줄 컴프리헨션 쓰면 괄호 짝 한 번 더 확인.
- 변수 shadowing — `d`(거리)를 `for d in range(4)`로 덮어씀 (4485). 핫루프 인덱스는 `i`/`d2` 등 충돌 없는 이름으로.
- **`main()` 정의 후 호출 누락 반복** (7576, 2206) — 작성 마지막에 `main()`/`if __name__` 존재 확인 루틴. *출력이 빈/0이면 가장 먼저 의심*
- **BFS 거리 갱신 시 기준 칸 혼동** (2206 신규) — `dist[새칸]=dist[현재칸]+1`인데 우변까지 `nx,ny`로 끌려감. 규칙: "좌변=새 칸(nx), 우변=현재 칸(x)"
- **행/열 혼동 (재발 중, 4회)** — 1600서 `grid[nx][ny]` 전치로 재발(`dist`는 (열,행) 규약인데 `grid`는 `[행][열]`). 근본 처방: **좌표를 `(행 r, 열 c)` 단일 규약으로 통일** → `dist[r][c]`·`grid[r][c]` 첫 인덱스가 같은 축이 되어 전치 실수 구조적 소거. (무발생 0/3 리셋)
- BFS 후 답 추출 검증 부족 — 시작점 dist 오해, early return 누락, `max(2D list)` 오용 등 (7576 1차)
- 상수/비교 일관성 — 상수 정의 후 매직넘버 직접 비교(7576 `==0`), `is` vs `==` 혼용(2206, small-int 캐싱으로 우연 통과). 같은 함수 내 비교 연산 통일할 것

## 자주 놓치는 패턴

> 2회 이상 반복된 실수만 등재.
> **해소 판정:** 단순히 N문제 지나간 게 아니라, 그 패턴이 **적용 가능했던 문제**에서 3회 연속 안 나와야 해소.
> "적용 가능 = 그 버그를 노출시킬 수 있는 유형의 문제" (예: BFS 패턴은 BFS 문제에서만 카운트).

| 패턴 | 적용 가능 카테고리 | 발생 | 마지막 발생 | 적용 후 무발생 | 상태 |
|---|---|---:|---|---:|---|
| 행/열 혼동 (경계 뒤집힘 / grid 전치 / 변수 오타) | 격자 이동 전체 | 4 | 2026-06-23 (1600) | 0/3 | 관찰중(재발) |
| 결과 출력 누락 (main 미호출 / `print` 빠뜨림 → 출력 없음) | main()·출력 쓰는 전체 | 3 | 2026-06-23 (13549) | 3/3 | 해소 |
| 리스트/제너레이터 생성 괄호 위치 오류 (`[X*n]`↔`[X]*n`, `f(x for..)`↔`f(x) for..`) | 파이썬 전체 | 3 | 2026-06-24 (4485) | 0/3 | 관찰중(3연속) |
| 위치 인덱스 매핑 오류 (시계방향 0~7 vs 직관적 12/3/6/9) | 회전 구조 (톱니, 주사위, 원판) | 1 | 2026-05-05 (14891) | 1/3 | 관찰중 |
| 공백 없는 숫자 문자열을 `.split()`으로 파싱 시도 | 격자/문자열 입력 | 1 | 2026-05-05 (14891) | 2/3 | 관찰중 |
| BFS visited를 popleft 시점에 표시 | bfs, multi-source bfs | 0 | - | 3/3 | 해소 |
| `input()` 사용 (sys.stdin.readline 누락) | 전체 | 0 | - | 3/3 | 해소 |
| 시뮬레이션 동시 변경 시 스냅샷 누락 | simulation | 0 | - | 0/3 | - |

> "적용 후 무발생" 컬럼: `현재 무발생 카운트 / 해소 임계값(3)`. 3/3에 도달하면 상태 → 해소, 다음 압축 시 제거 가능.
