## 기본 정렬 드릴 8개 / 총 45분

9/27 본 문제 전에 미완료 항목을 끝낸다. 각 항목을 3~5줄로 직접 작성하고 출력까지 확인한다. 막힌 문법은 확인한 뒤 예시를 바꿔 다시 쓴다.

| 체크 | 입력 | 할 일 |
|---|---|---|
| □ | `[3, 1, 3, 2]` | `sorted`로 원본을 보존하는 정렬, `sort`로 원본을 바꾸는 정렬을 각각 작성. 두 함수의 반환값 확인 |
| □ | `[4, -2, 0, 4, 1]` | 오름차순·내림차순 정렬. 중복은 유지 |
| □ | `['10', '2', '1', '20']` | 문자열 순서와 숫자 크기 순서로 각각 정렬하고 차이 설명 |
| □ | `['bb', 'a', 'ab', 'b', 'aaa']` | 길이 오름차순, 길이가 같으면 사전순 |
| □ | `[('kim', 80), ('lee', 90), ('ahn', 90)]` | 점수 내림차순, 동점이면 이름 오름차순. 전체 `reverse=True`와 차이 확인 |
| □ | `{'b': 2, 'a': 2, 'c': 1}` | 빈도 내림차순, 동률이면 키 오름차순으로 `(키, 값)` 목록 만들기 |
| □ | `[('A', 2), ('B', 1), ('C', 2), ('D', 1)]` | 숫자만 기준으로 정렬. 동점 항목의 기존 순서가 유지되는지 확인 |
| □ | `[40, 10, 30, 10]` | 값 오름차순의 **원래 인덱스** 목록 구하기. 동점이면 작은 인덱스 우선 |

끝나면 설명할 수 있어야 할 것: `sort`의 반환값, `key`가 만드는 값, 튜플의 비교 순서, 혼합 오름/내림차순, 안정 정렬. 기본 정렬은 O(N log N), 루프 안에서 매번 정렬하면 그 횟수만큼 비용이 붙는다.

### 제출 직전 6개

1. `sort()`·`append()`의 반환값을 답에 넣지 않았나?
2. 숫자를 문자열 순서로 비교하거나, `reverse=True`로 동률 기준까지 뒤집지 않았나?
3. 첫/마지막 원소, 전부 같은 값, 중복·동률, 길이 1을 처리했나?
4. 문자열의 연속 공백과 숫자 변환 조건을 지켰나?
5. 루프마다 정렬·슬라이싱·전체 합·`in list`를 반복해 느려지지 않나?
6. 리스트 공유·변수 덮어쓰기·방문 표시·`return` 누락이 없나?
