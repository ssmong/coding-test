# 9663. N-Queen [gold-4]

## 문제
N-Queen 문제는 크기가 N × N인 체스판 위에 퀸 N개를 서로 공격할 수 없게 놓는 문제이다.

N이 주어졌을 때, 퀸을 놓는 방법의 수를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 N이 주어진다. (1 ≤ N < 15)

## 출력
첫째 줄에 퀸 N개를 서로 공격할 수 없게 놓는 경우의 수를 출력한다.

## 예제
### 입력 1
```
8
```
### 출력 1
```
92
```

## 메모
- 제약 조건 핵심: N < 15 → 순진한 O(N^N)은 불가. 행 단위로 퀸을 1개씩 놓으면 각 행에서 N개 열 후보 → O(N!) 상한. N=14도 백트래킹 가지치기면 통과.
- 핵심: **한 행에 퀸 1개**라는 제약을 미리 걸면 "같은 행 충돌"은 자동 소거. row를 0→N-1로 내려가며 col만 고른다.
- 충돌 판정 3종: 같은 열 / ↘ 대각선(row+col 상수) / ↙ 대각선(row-col 상수).
- 함정: 대각선 판정을 `for` 루프로 지난 퀸 전부 훑으면(`(r,c) not in queens` 식) O(N)이라 느려짐 → **col/diag1/diag2 불리언 배열로 O(1) 판정**. diag2는 `row-col`이 음수라 `row-col+N-1`로 오프셋.
- 대칭성 최적화(선택): 첫 행을 절반만 탐색 후 ×2 (N 홀수면 가운데 열 별도 처리) → 상수배 단축. 시험장에선 O(1) 충돌배열만으로 충분.
- 엣지: N=1 → 답 1. N=2, N=3 → 답 0.
