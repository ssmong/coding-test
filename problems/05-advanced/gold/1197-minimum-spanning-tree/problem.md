# 1197. 최소 스패닝 트리 [gold-4]

| 시간 제한 | 메모리 제한 |
|---|---|
| 2 초 | 256 MB |

> ⚠️ 백준 접근 불가로 **기억 기반 재구성**. 예제 출력은 직접 크루스칼로 검증함(=3). 제약 수치·가중치 범위는 추후 확인 권장.

## 문제

그래프가 주어졌을 때, 그 그래프의 최소 스패닝 트리를 구하는 프로그램을 작성하시오.

최소 스패닝 트리는, 주어진 그래프의 모든 정점들을 연결하는 부분 그래프 중에서 그 가중치의 합이 최소인 트리를 말한다.

## 입력

첫째 줄에 정점의 개수 V(1 ≤ V ≤ 10,000)와 간선의 개수 E(1 ≤ E ≤ 100,000)가 주어진다. 다음 E개의 줄에는 각 간선에 대한 정보를 나타내는 세 정수 A, B, C가 주어진다. 이는 A번 정점과 B번 정점이 가중치 C인 간선으로 연결되어 있다는 의미이다. C는 음수일 수도 있으며, 절댓값이 1,000,000을 넘지 않는다.

그래프의 정점은 1번부터 V번까지 번호가 매겨져 있고, 임의의 두 정점 사이에 경로가 있다(연결 그래프). 최소 스패닝 트리의 가중치가 -2,147,483,648보다 크거나 같고, 2,147,483,647보다 작거나 같은 데이터만 입력으로 주어진다.

## 출력

첫째 줄에 최소 스패닝 트리의 가중치를 출력한다.

## 예제

### 입력 1
```
3 3
1 2 1
2 3 2
1 3 3
```
### 출력 1
```
3
```

## 메모

- **카테고리:** MST. **새 개념 2개** — ① 크루스칼(간선 정렬 + 사이클 판정) ② **유니온-파인드(Disjoint Set Union)**.
- **두 접근:**
  - **크루스칼:** 간선을 가중치 오름차순 정렬 → 작은 것부터, **사이클 안 생기면(두 끝이 다른 집합)** 채택. 사이클 판정에 union-find. 간선 위주라 여기 **간선 리스트**가 맞는 자료구조.
  - **프림:** 정점 하나에서 시작, heapq로 "트리에 닿는 가장 싼 간선" 반복 추가. 다익스트라랑 골격 비슷.
- **유니온-파인드 핵심:** `find`(대표 찾기, 경로 압축) + `union`(두 집합 합치기). 두 정점이 같은 집합이면 잇는 순간 사이클.
- **종료 조건:** 간선 V-1개 채택하면 트리 완성 → 조기 종료 가능.
- **함정:** 간선은 **양방향**(무향). 가중치 음수 가능하지만 MST 알고리즘엔 무관(부호 상관없이 작은 것부터).
